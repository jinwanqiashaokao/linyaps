# 2024年下半年工作评语

## 工作内容总结

本同志在2024年下半年表现出色，主要负责龙蜥社区和CGSL操作系统在RISC-V架构上的适配与优化工作。工作内容涵盖多个关键技术领域：

**系统构建与测试方面：** 成功完成龙蜥社区23.4版本的构建工作，分析并解决了9个构建失败组件的问题；编写了RISC-V发行版通用测试集测试项，为RISC-V架构的测试标准化奠定了基础。

**GCC14工具链适配方面：** 完成了CGSL v7和龙蜥社区在RISC-V架构上的GCC14重新构建工作，对20+个失败组件进行了深度适配分析并向CGSL提交了补丁；完成了gcc、binutils等GCC14工具链的适配及补丁合入；通过system-rpm-config组件成功添加rva23u64相关编译参数；完成了GCC 14.3对齐12.3版本与欧拉系统的工作。

**版本升级与联调支持方面：** 完成大版本升级工具支持三方OS升级至v7的穿刺和开发工作，成功支持了新支点的国测升级演示；积极参与TECS RISC-V联调版本的故障分析，排查并解决了openssh的error打印、cgsl-diagnosis运行报错等多个os问题；修复了因repo组件改变引起的atlas组件构建失败问题。

**组件对齐与优化工作：** 完成了RISC-V组件对齐x86和arm架构的构建工作，进行了失败组件分析并完成补丁入库；基于GCC14工具链对CGSL组件进行了滚动编译；分析并解决了GCC14工具链编译出的二进制文件在算能服务器上运行时的core dump问题。

## 工作肯定

该同志在下半年的工作中展现了扎实的技术功底和出色的问题解决能力。面对RISC-V架构适配这一前沿技术挑战，能够独立完成从系统构建、工具链适配到问题排查的全流程工作。特别值得肯定的是：在GCC14适配过程中，能够系统性地分析失败组件，提交高质量补丁，保障了联调版本的按时发布；在版本升级和故障分析方面表现出较强的责任心和技术深度，为项目的顺利推进做出了重要贡献。工作态度认真负责，技术方案扎实可靠，是团队中的技术骨干。

## 改进建议

建议在以下几个方面进一步提升：一是加强工作过程中的文档沉淀，将技术问题的分析过程、解决方案和经验教训进行系统性总结，形成可复用的技术文档，便于团队知识传承；二是提升跨团队沟通协作能力，在涉及多方配合的工作中可以更主动地推动问题解决，提高整体工作效率；三是建议在完成具体技术任务的同时，适当关注技术趋势和架构设计层面的思考，培养更全面的技术视野，为未来承担更重要的技术决策工作做好准备。
